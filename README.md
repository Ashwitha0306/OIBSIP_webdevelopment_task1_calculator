Smart Calculator Pro

A modern and responsive web-based calculator application built using HTML, CSS, and JavaScript. Smart Calculator Pro provides basic arithmetic operations along with additional utility tools such as Percentage Calculator, Discount Calculator, and GST Calculator. The application also includes calculation history tracking, dark/light theme switching, and an attractive modern UI.
